The scanned handwritten pages themselves are not stored in this repo (they are large binary files that would permanently bloat the history). If a figure ever needs re-deriving, the scan page is the fallback — see the README for where the scans live.

## Adding or replacing a figure

1. Drop the PNG in `figures/`, named `chNN-C-F-slug.png` (`NN` = chapter, `C` = chapter number, `F` = figure number).
2. Reference it from the chapter as a numbered figure div with an id (`::: {#fig-NN}`) and a caption whose bold title ends with a period.
3. Add it to the HTML gallery in `gallery.qmd` with the same `Figure N.F` number and a thumbnail link back to the chapter anchor.
4. Add a row to the table above.
